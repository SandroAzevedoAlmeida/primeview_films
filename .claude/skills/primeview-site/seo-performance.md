# PrimeView Filmes — SEO e Performance

## SEO principal

Title:
`PrimeView Filmes | Produção Audiovisual Imobiliária`

Description:
`Produção audiovisual para corretores, imobiliárias e empreendimentos. Vídeos imobiliários, drone 4K, fotografia profissional e Tour Virtual 360°.`

## Metadata

Configurar:
- title;
- description;
- canonical;
- Open Graph;
- Twitter/X Cards;
- favicon;
- sitemap;
- robots.txt.

OG image:
`public/assets/brand/og-image.jpg`

## Schema.org

Usar schema apropriado, como `Organization`, sem inventar CNPJ, endereço completo, reviews, preços ou prêmios.

## SEO local

Usar naturalmente:
- Serra;
- Espírito Santo;
- produção audiovisual imobiliária;
- vídeos imobiliários;
- fotografia imobiliária;
- drone para imóveis;
- Tour Virtual 360°;
- corretores;
- imobiliárias;
- construtoras.

Evitar keyword stuffing.

## Imagens

Preferir AVIF/WebP, dimensões definidas, alt text e lazy loading fora da primeira dobra.

## Hero e LCP

Tratar Hero como elemento crítico.
Não usar lazy loading se piorar LCP.
Evitar vídeo pesado em autoplay no mobile.

## Vídeos

Thumbnail → clique → player.

## JavaScript

Mínimo possível. Não hidratar conteúdo estático.

## Fontes

No máximo duas famílias e poucos pesos.

## Core Web Vitals

Priorizar LCP, CLS e INP.

## Lighthouse

Buscar bons resultados em Performance, Accessibility, Best Practices e SEO sem sacrificar a estética premium.

- HTML semântico
